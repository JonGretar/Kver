# Linux archive

Run `sh packaging/linux/package.sh` on x86-64 Ubuntu 24.04. It builds, packages,
and verifies the tarball and checksum without publishing. The archive includes
the user-level launcher installer; Arch Linux uses a [separate recipe](../arch/).

See [build prerequisites](../../docs/development.md) and the
[Linux download and installation guide](../../docs/linux.md).
